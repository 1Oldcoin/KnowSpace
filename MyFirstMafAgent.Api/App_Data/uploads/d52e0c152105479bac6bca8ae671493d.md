## 第11章 侯小妹

**概要**：马脸杂役听白小纯说还能给他机会，又看到白小纯身后的张大胖与黑三胖，衡量得失后决定出灵石买名额，讨价还价后定在十六个灵石，把钱袋扔给白小纯三人。出口旁两个外门弟子当场指责他们公然贩卖外门弟子名额，张大胖回话说爬累了不想爬、让给同门并收些补偿，两个外门弟子一时无法反驳。随后试炼台阶上来了七八个气喘吁吁的杂役，最前方是赤着上身的三十多岁大汉，白小纯上前推销名额，大汉骂他小崽子并挥出凝气三层后期的灵压，白小纯喊来张大胖，张大胖从天而降坐在大汉身上，又把大汉砸得惨叫，大汉举手交出钱袋求饶，被安排在马脸杂役身边排队。后方七八个杂役看到这一幕后觉得有了机会，白小纯宣布最后一个名额价高者得，众人当场叫价。侯小妹自报家中是修真家族、不缺灵石，出三十个灵石压过众人，最终买下名额。马脸杂役、自称狼爷的大汉与侯小妹踏上最后一处台阶离开试炼之地，白小纯三人抱拳相送，马脸杂役与大汉相视苦笑，侯小妹则振奋得意。

**关键事件**：1.白小纯与马脸杂役砍价，定下十六个灵石买名额 2.张大胖将赤身大汉坐压砸打，逼其交出补偿 3.白小纯把最后一个名额改为价高者得，侯小妹出三十个灵石买下 4.马脸杂役、狼爷、侯小妹三人走出试炼之地成为外门弟子

**逐章写法公式**：

- **情绪流向**：起：马脸杂役被拦下、名额还得加钱 → 承：白小纯报价砍价、外门弟子指责、张大胖坐压大汉 → 转：白小纯把最后名额改成价高者得，侯小妹入场抬价 → 合：三人踏出试炼之地，白小纯三人抱拳相送、买家苦笑
- **节奏配比**：慢铺垫 20% / 快冲突 30% / 爽点爆发 40% / 悬念留白 10%
- **本章结构公式**：开价谈判卖出第一个名额（立买卖规则） + 张大胖压制拒付的大汉（立暴力执行） + 白小纯改拍卖、侯小妹高价成交（抬价升级） + 三人出门受贺、买家苦笑（反讽收口）
- **本章核心技巧**：同一桩交易重复三次且一次比一次离谱，用旁观者的反应层和买家事后的情绪落差代替作者评价
- **卡点与伏笔**：结尾卡点：无强悬念卡点，以三人踏出试炼之地、白小纯三人抱拳祝贺与买家苦笑收束本章；埋设/回收伏笔：侯小妹的修真家族与灵石家底 → 第14章其兄候云飞出场并向白小纯道谢；马脸杂役的心思 → 衬托试炼之路堵门带来的连锁效应

## 第13章 你也来吧！

**概要**：监事房与火灶房的争斗已持续多年，彼此把握尺度不让事情闹大，这次因试炼之路掀起的打斗持续一炷香，陈飞等人被张大胖等人打得鼻青脸肿，各自拿出几块灵石赔偿大门后放狠话离去，陈飞临走回头看了站在篱笆墙上的白小纯，恨意更多。这场打斗引起整个杂役区关注，南岸杂役发现监事房对火灶房无可奈何，一些杂役像侯小妹一样觉得火灶房的行为对自己是好机会。第二个月试炼之路再次开启，火灶房众人早早守在入口，张大胖按白小纯教的话说他们是为了宗门、为了让大家有竞争力，众杂役咬牙，试炼开启后众人玩命冲去，很快被火灶房的身影甩开。此后又过去两个月，每逢试炼之路开启火灶房众人就飞奔而去，名气达到火灶房历史巅峰，白小纯的灵石越来越多，即将攒够购买药草所需。又一次试炼之路开启的清晨，九人飞奔而去，途中监事房的人随意找理由与白小纯三人打斗，人数占优使混战时间变久，直至钟声回荡，监事房众人一哄而散，张大胖来不及追击。三人赶到香云山试炼之路，眼看四周人少便赶紧上山，张大胖怒说下山后要砸了监事房，体内脂肪剧烈燃烧、身体瘦了一圈、速度暴增，白小纯也提速，三人一路超越前方杂役，快到山顶时发现陈飞与两个凝气三层的大汉站在靠近出口的位置。陈飞大笑说来晚了、他这里刚好有名额，还说既然不违反门规、火灶房能来监事房一样能来、生意以后归监事房。张大胖与黑三胖正要出手，白小纯低声提议使劲跑，把陈飞三人推上山，宁可这次不要灵石也要断了监事房抢生意的路。张大胖与黑三胖并排横在狭窄山路上冲撞，陈飞三人的反击反而加速自己后退，他们不想这么快成为外门弟子、怕少了油水，陈飞开口求饶被白小纯尖声打断。陈飞身后的两个大汉先后被撞出试炼之路站上山顶，陈飞最终也被撞出去，眼红如要杀人，最恨出损招的白小纯。山顶上两个负责的外门弟子干咳退后没有说话，张大胖与黑三胖嚣张大笑，陈飞三人气得吐血，白小纯抬下巴道贺，话音未落，香云山山顶传来冰冷的声音说不用羡慕了、你也来吧，一股巨大吸力笼罩白小纯把他卷向山顶，白小纯抱住树干惨叫喊师兄救我，树干折断，他被卷到山顶，李青候从山顶走出。

**关键事件**：1.陈飞等人赔灵石离场，双方仇怨加深 2.试炼之路再开，火灶房连续数月堵路卖名额，名气达到历史巅峰 3.监事房中途拦打拖延，又抢先占住山顶出口，宣称生意归监事房 4.白小纯提议把陈飞三人推上山，宁可不要灵石也要断了监事房的生意 5.陈飞三人被先后撞出试炼之路成为外门弟子 6.李青候出手将白小纯卷上山顶

**逐章写法公式**：

- **情绪流向**：起：陈飞赔钱离开、火灶房把生意做成每月例行 → 承：监事房拦打拖延并抢占山顶出口 → 转：白小纯提议把三人推上山，陈飞三人被逐一撞出 → 合：白小纯得意道贺时被李青候卷上山顶
- **节奏配比**：慢铺垫 25% / 快冲突 30% / 爽点爆发 30% / 悬念留白 15%
- **本章结构公式**：上章打斗收尾与名气累积（时间跳跃） + 监事房拦截并抢先占出口（对手反制） + 白小纯改换目标把三人推上山（解法升级） + 李青候出手点名白小纯（强压制收尾）
- **本章核心技巧**：让对手把主角的招式照搬回来制造僵局，再让主角用放弃眼前灵石换取断绝对手生意的解法破局，收尾用更大的力量直接压住主角
- **卡点与伏笔**：结尾卡点：危机型卡点，白小纯被李青候卷上山顶、张大胖与黑三胖来不及反应，下章期待李青候如何处理火灶房众人；埋设/回收伏笔：陈飞对白小纯的恨意 → 本章末尾与第12章的宿怨延续；李青候的出现 → 第14章宣布三人去处并揭开黑三胖的性别

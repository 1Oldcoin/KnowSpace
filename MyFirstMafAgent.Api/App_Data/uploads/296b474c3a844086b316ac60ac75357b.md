## 第5章 万一丢了小命咋办

**概要**：木剑落入锅中后没有特别变化，白小纯不甘心地盯着看了半天，随后看了眼龟纹锅上的纹路与火灶内的木头灰烬，若有所思，转身出去向张大胖要了几块与之前火灶内一样的木头。他点燃木头后，龟纹锅上第一条纹路再次明亮，木火急速燃烧后渐渐熄灭，锅内的木剑突然银光刺目，白小纯后退几步，光芒消散后他感到一股凌厉之意从锅中传出。他小心靠近，看到锅内木剑出现了一道与灵米一样的刺目银纹，此纹慢慢暗去成为暗银色，剑身虽仍是木质却给人金属的锋利之意，重量也重了一些。他确认木剑成功炼灵一次，狂喜并爱不释手，决定把那口锅放在原处，因为越是如此越没人在意；灵米吃了就是，木剑则轻易不可让人看到。数日后的夜晚，他把搜集来的各色汁液刷在木剑上，使剑看起来五颜六色、破破烂烂，再操控一番发现灵纹被盖住不少，这才满意。接下来的日子里他在火灶房如鱼得水，与师兄打成一片，熟悉了火灶房的工作，明白不同灵食需要不同的火，还分一色火、二色火，也明白龟纹锅下的木头就是产生一色火的灵木。几个月后他渐渐胖了起来，已不再是刚入宗门时的干瘦，胖了好几圈却更白净，越发人畜无害，向白九胖这个名字靠近。加餐之事又经历了几次，他体重见涨但修行始终缓慢，后来索性不去想，整天与师兄吃吃喝喝。他从张大胖处听到宗门分内门与外门弟子，杂役若修行到凝气三层就可去闯各峰的试炼之路，成功可拜入所试炼之峰成为外门弟子，各峰试炼之路每月开启只取前三，一年到头成为外门弟子的人数固定。这一日原本该七胖下山采购，因事耽搁，张大胖让白小纯下山一趟。白小纯回房取七八把菜刀、穿五六件皮衣，又找一口结实的锅背在背上，摇摇晃晃走出火灶房下山。他走在青石路上感慨白驹过隙，途中杂役纷纷侧目，几个女弟子被他的样子逗得掩口轻笑，他圆脸微红，觉得自己越发威武，昂首挺胸向前走。没过多久他还没走出第三峰杂役区，就看到不少杂役神色振奋地向第三峰山路跑去，他抓住一个最瘦弱的少年询问，得知外门弟子中的天骄周宏与张亦德因私怨在山下试炼场斗法，二人都已是凝气六层。白小纯跟着人流到第三峰山脚下，看到千丈大小的庞大高台，四周密密麻麻围着无数杂役，山上还有衣着华贵的外门弟子观望。高台上两人衣袍一样华贵，一人脸上有疤，一人面白如玉，身影交错并传出轰鸣；疤脸青年面前一面小旗无风自动，形成一头雾虎咆哮，面白如玉的青年用一把蓝色小剑划出灵痕灵活呼啸。白小纯自己也能操控木剑，但与对方根本无法相比；这二人出手杀气腾腾、身上多处伤口，白小纯第一次看到修士斗法，觉得与他印象中的仙人截然不同，那种凶狠与戾气让他心惊肉跳。他想修仙只是为了长生，觉得外面太危险，还是回火灶房安全，于是赶紧后退。就在他退后的同时，一声大吼传来，许宝财一脸狞笑向他冲来，其身前一把木剑散出不同寻常的光芒，划出弧形带灵压直奔他而来。白小纯瞳孔一缩，感到强烈的生死危机，发出一声凄厉惨叫拔腿就跑，大喊杀人了杀人了，声音之大让四周杂役纷纷看去，连高台上斗法的周宏与张亦德也彼此停顿了一下。许宝财被吓了一跳，他明明只是喊了名字追过来，剑还没碰到对方。许宝财面铁青地让他别跑，白小纯边惨叫边答要有本事早弄死他了，速度极快如同一只胖胖的兔子，转眼快看不到影。与此同时，第三峰顶端一处悬出的庭阁内，李青候与满头白发、面色红润、目内流光四溢的老者相对下棋，老者扫了眼山下笑着说李青候带回来的小娃有些意思，李青候说此子性格还需再多磨炼一番，并有些头疼地摇头。老者说火灶房那几个孩子都心高气傲，此子能与他们打成一片不简单，眼中露出揶揄之意。

**关键事件**：1.白小纯用灵木点火，锅内木剑出现银纹，炼灵一次成功 2.白小纯决定把锅留在原处，并刷汁液盖住木剑灵纹 3.几个月里白小纯熟悉火灶房工作，了解一色火二色火并渐渐变胖 4.白小纯从张大胖处得知凝气三层可闯试炼之路成为外门弟子 5.张大胖派白小纯下山采购，他带菜刀皮衣与锅出门 6.白小纯看到周宏与张亦德在山下试炼场斗法 7.许宝财持木剑追杀白小纯，白小纯惨叫逃跑 8.李青候与掌门在峰顶下棋谈及白小纯

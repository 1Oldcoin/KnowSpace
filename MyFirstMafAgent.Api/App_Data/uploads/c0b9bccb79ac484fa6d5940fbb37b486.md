## 第20章 一地鸡毛

**概要**：原文先交代灵尾鸡身体比寻常家鸡巨大很多、羽毛坚硬、习性凶猛，成年后堪比凝气二层，肉可食、蛋可滋补、血与骨能入药，尤其尾巴是三色火的燃烧，因此在灵溪宗南岸三山都有大量饲养，但归李青候与其他两座山掌座私人所有，香云山上有三处圈起区域专供繁殖。白小纯蹲在草丛里看着灵尾鸡，他以前在火灶房没见过活的却吃过肉，也听张大胖说此鸡喜吃灵虫。他没有轻举妄动，先下山用所剩不多的灵石换来一袋灵虫，回到院子后又饿了，看到已长到一丈多长、拳头粗细、散发灵芒的灵冬竹后，按所学草木知识取下一根灵冬竹最坚硬的两截竹头，做出小时候跟他爹学的竹知了，又用竹丝编成绳索与竹知了连接，趁夜色飞奔到最近的饲养处。他蹑手蹑脚靠近栅栏，把挂着灵虫的竹知了扔进去，蹲在旁忍饥等待。一只灵尾鸡啄住灵虫触动机关，被掰弯的竹子弹开卡住鸡嘴使其无法出声，任凭挣扎也被大力快速拽动，绳索一抖灵尾鸡被拽得飞起，白小纯一把抓住，以凝气四层的修为与坚韧的皮一拧鸡脖子扔进储物袋，全程用时不到三十息。他回到院子，天亮时那只鸡已完全进了肚子，只剩一地鸡毛与鸡骨头。吃下这只灵尾鸡后饥饿感消散大半，体内灵气多了一丝，不死长生功一口气运转了七八个呼吸循环。他判断不死皮分金银铜铁四层，自己如今只是入门，呼吸九九八十一天可达不死铁皮小成，因此觉得山上的灵尾鸡足够多。他把鸡骨头与鸡毛埋进灵土，又到外门弟子人多处打探，没听到灵尾鸡丢失的议论，却偶然得知灵尾鸡的三色尾是三色火的燃料，随即跑回院子把三色尾挖出收起，打算有了灵药再用。数日后他又饿了，深夜再偷回两只灵尾鸡。一个月过去，香云山渐渐传出灵尾鸡丢失，三处饲养地丢失达数十只，连李青候都知晓但因有事要外出没有理会，负责饲养的七八名外门弟子觉得没有面子，可无论怎么守护鸡还是无声无息地丢。白小纯这一个月身体恢复如常甚至略胖一圈，研究草木第二篇的速度也提高，终于把第二篇完整研究透彻，连叶茎、根脉、绒毛都烂熟于胸，哪怕分裂成数十份也能一眼认出，随后昂首挺胸走出院子直奔万药阁。

**关键事件**：1.白小纯先买灵虫、用灵冬竹做出竹知了与绳索，再夜入饲养处偷灵尾鸡 2.白小纯偷鸡全程不到三十息，天亮前吃完全鸡，饥饿感消散大半 3.白小纯得知灵尾鸡三色尾是三色火燃料，挖出羽毛收起备用 4.一个月内三处饲养地丢失数十只灵尾鸡，李青候知晓但因要外出未理会 5.白小纯研究透彻草木第二篇，动身前往万药阁

**逐章写法公式**：

- **情绪流向**：起：先摆灵尾鸡的来历与价值 → 承：备料做竹知了，夜入饲养处无声偷鸡 → 转：鸡肉兑现修为与饥饿的缓解，并发现三色尾的用途 → 合：一月偷数十只无人查获，草木第二篇研究透彻，昂首去万药阁
- **节奏配比**：慢铺垫 30% / 快冲突 25% / 爽点爆发 35% / 悬念留白 10%
- **本章结构公式**：设定与归属交代（把风险抬上去） + 作案准备与执行（给可看的手艺过程） + 收获兑现与工具升级（三色火燃料） + 偷鸡规模化与草木第二篇完成（把下章的目标打开）
- **本章核心技巧**：把一次违规行为按工序写完，让每一次成功都立刻兑换成修为与下一件工具，再用受害者的郁闷把主角的隐藏战绩垫高。
- **卡点与伏笔**：结尾卡点：期待型卡点，白小纯研究透彻草木第二篇后直奔万药阁，要让人知道自己是骑在周心琪上面的龟爷，下章期待他公布身份；埋设/回收伏笔：竹知了与竹丝绳索 → 成为长期偷鸡的工具；三色尾羽可作三色火燃料 → 为炼灵三次的升级埋线；饲养弟子与李青候都未查获 → 为偷鸡事件的暴露埋线；鸡骨头鸡毛埋进灵土 → 与上章炼灵灵田的行为形成呼应

## 第9章 延年益寿丹

**概要**：一个月后寒风渐起，白小纯发现自己来到灵溪宗已有一年，修为是凝气三层，许宝财远远见到他也赶紧避开。白小纯为被龟纹锅抽走的一年寿元发愁，尝试滋补无效，打听后知道补寿之法有限制或极罕见。一天午后他在第三峰下看到接受宗门任务的石碑，在上面看到延年益寿丹的任务，问到此丹可增加一年寿元、只能凝气五层以下使用且只有第一次有效。他接下任务，需要青灵叶、地龙果、石虫皮三样药材。他在四海房查到青灵叶生长于候灵鸟栖息之地，这种鸟一只堪比凝气二层；地龙果与石虫皮没有记录，石虫皮南岸很少、北岸才有。他下山去坊市转了一圈，发现换不到丹药。随后宗门响起钟鸣，他想到每月开放的试炼之路，喊来张大胖等人提出一个发财的点子。

**关键事件**：1.白小纯为补回被抽走的一年寿元，接下换取延年益寿丹的任务 2.白小纯查清青灵叶、地龙果、石虫皮三样药材的来历与产地，去坊市后发现买不起 3.白小纯听到钟鸣后想到试炼之路，召集师兄们提出一起发财的点子

**逐章写法公式**：

- **情绪流向**：起：一年过去的感慨与寿元缺失的愁苦 → 承：发现延年益寿丹任务的希望 → 转：药材与价格把希望压回去 → 合：钟鸣引出试炼名额的生财思路
- **节奏配比**：慢铺垫 60% / 快冲突 5% / 爽点爆发 10% / 悬念留白 25%
- **本章结构公式**：一年回顾（状态交代） + 石碑与延年益寿丹（目标确立） + 药材与坊市（障碍堆叠） + 钟鸣与发财点子（思路反转）
- **本章核心技巧**：先立一个具体到药材清单的目标，再用产地、身份、价格三重障碍把它推远，最后用一个制度规则给出绕开障碍的解法。
- **卡点与伏笔**：结尾卡点：悬念卡点，白小纯只说有发财的点子却不说内容，下章期待方案揭晓；埋设/回收伏笔：被抽走的一年寿元 → 本章的任务动机；火灶房灵食被监事房盯着 → 不能靠卖灵食赚钱；炼灵之物不能卖 → 为后续保密埋线；每月钟鸣的试炼之路 → 下一章赚钱方案的核心规则

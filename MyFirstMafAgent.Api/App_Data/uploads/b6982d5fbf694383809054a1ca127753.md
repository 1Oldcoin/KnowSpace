## 第12章 篱笆墙上

**概要**：杂役晋升外门弟子的试炼结束后，侯小妹三人远去，张大胖望着侯小妹的背影摸着下巴说她白白的、小小的、纯纯的，又瞄向白小纯，白小纯大叫别看我，张大胖拿出装灵石的口袋转移话题并提出数灵石，说看的是灵石数的是人生。试炼之路上光芒闪耀，众人被送回山下，开启试炼之路的中年执事看到三人后面色古怪，摇头不再理会，打算把火灶房的事交给宗门处理。三人相互干咳几声快步回到火灶房，其他几个胖子师兄也回来了，各自分到一份灵石；白小纯把灵石扔在草屋，说明自己的追求是长生，若非为买草药换延年益寿丹也不会想出赚灵石的主意。这一夜火灶房众人都没睡好，张大胖等人因乍富激动，又回想数年口袋干瘪、遥想未来，随后后怕忐忑而失眠，白小纯想着延年益寿丹同样失眠。第二天，堵门的事在灵溪宗南岸杂役区一传十十传百，几乎无人不知，杂役区内所有人几乎都在讨论火灶房，火灶房这几天低调，众人几乎从不单独外出。数日后黄昏，白小纯正在往底很厚的大碗里倒米汤，监事房的人奉命前来调查，大门被踢开，十多个穿监事房衣衫的杂役闯入，当首的是之前为许宝财出头的那个虎背熊腰的大汉陈飞。陈飞问火灶房九人是否参加试炼、是否堵住出口贩卖名额，白小纯与张大胖等人坦然承认，陈飞察觉到对方过于镇定而心生不妙，仍喝令众人随他去执法堂，说反抗者逐出宗门。白小纯指出监事房只有问询资格、没有抓人资格，又追问他们犯了哪一条门规，陈飞发现门规内没有不允许贩卖试炼路外门名额的说法，额头冒汗，白小纯则说陈飞欺骗执法堂、公报私仇、动私刑，触犯门规第九卷第十一条；张大胖等人随后指出火灶房的大门需要赔偿，喊打动手，白小纯站到篱笆墙上装作深沉。

**关键事件**：1.试炼结束后三人回火灶房分灵石，火灶房众人当夜失眠 2.堵门卖名额的事在南岸杂役区传开，火灶房低调避人 3.陈飞率十多个监事房杂役踢开大门前来调查并要抓人 4.白小纯指出监事房无抓人资格、门规也没有禁止贩卖名额的条款，陈飞额头冒汗 5.张大胖以赔偿大门为由带众胖子动手，白小纯站上篱笆墙

**关键信息与扩写技法**：

| 关键信息/剧情走向 | 原文如何扩写 | 扩写技法 | 对读者情绪的作用 | 可复用提醒 |
|---|---|---|---|---|
| 试炼堵门卖名额在杂役区全面传开 | 不直接写名声，而是写第二天起一传十十传百、杂役区所有人几乎都在讨论，再放三句杂役的议论，其中一句是嫉妒自己没想到这个主意 | 反应层放大 | 搞笑 | 用不同立场的旁观者议论同一件事，把名声扩散写成对话串而不是叙述结论 |

**逐章写法公式**：

- **情绪流向**：起：试炼结束、三人分灵石、火灶房彻夜失眠 → 承：事情传遍杂役区、火灶房低调躲人 → 转：陈飞踢门拿人、白小纯反问门规、陈飞额头冒汗 → 合：以赔偿大门为由动手，白小纯站上篱笆墙收尾
- **节奏配比**：慢铺垫 30% / 快冲突 30% / 爽点爆发 30% / 悬念留白 10%
- **本章结构公式**：分灵石与失眠等余波（交代收获与风险） + 传言扩散的旁观者议论（抬高风险） + 陈飞上门问询与抓人（制造压迫） + 白小纯用门规反问反制、众胖子动手（反转收尾）
- **本章核心技巧**：把冲突的胜负提前埋伏在主角早已翻烂门规这一信息里，正面场景只放大对手找不到条款的窘态
- **卡点与伏笔**：结尾卡点：冲突型卡点，打斗刚开始、白小纯站上篱笆墙并说出弹指间监事房灰飞烟灭，下章期待看到打斗结果与后续比试；埋设/回收伏笔：白小纯两个月前提出堵门想法时众人已把门规翻烂 → 本章陈飞找不到禁止条款的依据；白小纯的木剑 → 逼停陈飞的冲势

## 第1章 他叫白小纯

- **本章功能**：1.村民送别白小纯，白小纯走远后村民敲锣打鼓庆祝 2.白小纯上山被灌林声吓到，拿出斧头柴刀和黑香 3.白小纯第十三次点燃祖传香，雷电大作 4.李青候现身熄灭香，追问点香三年的原因 5.李青候用神识听到山下欢呼，白小纯改口说怕死想长生 6.李青候带白小纯飞往灵溪宗

- **场景节点（含目的）**：

  - 送别场景建立反差人设（铺垫）
  - 山林遇险展示装备与怕死（行动）
  - 点香引发天地异象（信息揭示）
  - 仙人现身与神识拆穿（转折点）

- **情绪流向**：起：看似温情送别，实则全村送瘟神 → 承：山上遇险，掏出武器与祖传香 → 转：十三次点香惊雷，仙人真的降临并追问 → 合：白小纯改口认怂，被卷上天带走
- **节奏配比**：慢铺垫 35% / 快冲突 15% / 爽点爆发 25% / 悬念留白 25%
- **本章核心技巧**：用两套相反的反应对待同一件离开的事，让人物的乖巧外表与坏水内心同时成立

- **结尾卡点**：信息类卡点，主角被带上天却只听到灵溪宗三个字，下章期待看到仙门全貌与他如何立足

- **伏笔**：祖传黑香与白家祖上救仙人的旧人情 → 引出李青候与白家血脉的入门资格；白小纯点香十二次的记录 → 为李青候三年奔波提供原因

- **本章功能**：1.白小纯完成不死长生功九九八十一天的小周天，剧痛消失、皮肤坚韧、速度翻倍 2.白小纯修行身体呼吸法后暴瘦并陷入极度饥饿 3.白小纯冲入火灶房连喝一百多口锅米汤，按六句真言只吃边角 4.白小纯听到鸡鸣，蹲在饲养灵禽处栅栏外觊觎鸡群

- **场景节点（含目的）**：

  - 孤独日常与灵冬竹长势（做反差底色）
  - 八十一天苦修兑现（给第一波爽）
  - 新代价引发厨房闹剧（喜剧化失控）
  - 鸡鸣引出下一章目标（把胃口变成钩子）

- **情绪流向**：起：外门日子滋润却偏僻孤独 → 承：九九八十一天小周天成，剧痛消失速度快一倍 → 转：新呼吸法带来暴瘦与疯狂饥饿，冲进火灶房连喝米汤 → 合：被饥饿逼上山，听到鸡鸣蹲到灵禽栅栏外
- **节奏配比**：慢铺垫 35% / 快冲突 20% / 爽点爆发 20% / 悬念留白 25%
- **本章核心技巧**：把长期苦修的回报当场兑成身体数据，同时立刻用一个新的生理代价把主角推向下一个尴尬又危险的目标。

- **结尾卡点**：行动悬念型卡点，白小纯蹲在灵禽栅栏外盯着三色尾羽的鸡，下章期待他是否下手及后果

- **伏笔**：不死长生功第二阶段的呼吸法与饿 → 为偷鸡长期化埋线；灵禽与三色尾羽 → 为三色火燃料埋线；火灶房六句真言 → 为后续维护火灶房师兄的情义线埋线

## 第20章 一地鸡毛

- **本章功能**：1.白小纯先买灵虫、用灵冬竹做出竹知了与绳索，再夜入饲养处偷灵尾鸡 2.白小纯偷鸡全程不到三十息，天亮前吃完全鸡，饥饿感消散大半 3.白小纯得知灵尾鸡三色尾是三色火燃料，挖出羽毛收起备用 4.一个月内三处饲养地丢失数十只灵尾鸡，李青候知晓但因要外出未理会 5.白小纯研究透彻草木第二篇，动身前往万药阁

- **场景节点（含目的）**：

  - 设定与归属交代（把风险抬上去）
  - 作案准备与执行（给可看的手艺过程）
  - 收获兑现与工具升级（三色火燃料）
  - 偷鸡规模化与草木第二篇完成（把下章的目标打开）

- **情绪流向**：起：先摆灵尾鸡的来历与价值 → 承：备料做竹知了，夜入饲养处无声偷鸡 → 转：鸡肉兑现修为与饥饿的缓解，并发现三色尾的用途 → 合：一月偷数十只无人查获，草木第二篇研究透彻，昂首去万药阁
- **节奏配比**：慢铺垫 30% / 快冲突 25% / 爽点爆发 35% / 悬念留白 10%
- **本章核心技巧**：把一次违规行为按工序写完，让每一次成功都立刻兑换成修为与下一件工具，再用受害者的郁闷把主角的隐藏战绩垫高。

- **结尾卡点**：期待型卡点，白小纯研究透彻草木第二篇后直奔万药阁，要让人知道自己是骑在周心琪上面的龟爷，下章期待他公布身份

- **伏笔**：竹知了与竹丝绳索 → 成为长期偷鸡的工具；三色尾羽可作三色火燃料 → 为炼灵三次的升级埋线；饲养弟子与李青候都未查获 → 为偷鸡事件的暴露埋线；鸡骨头鸡毛埋进灵土 → 与上章炼灵灵田的行为形成呼应

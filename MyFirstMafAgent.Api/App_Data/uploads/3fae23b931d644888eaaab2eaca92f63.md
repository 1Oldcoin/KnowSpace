## 开篇判断

- **开篇钩子类型与效果**：反差钩，强。第1章先写标准温情送别——乡亲不舍、老者以长生相劝、少年转身迈步；少年一走远，全村立刻敲锣打鼓、老者流泪喊出「苍天有眼，这白鼠狼，他终于……终于走了」。同一场戏的 180 度翻转，让主角性格不用一句旁白就立住。
- **主角立人设手法**：三重叠加——他人评价（外号「白鼠狼」、村民追查「是谁说附近有仙人」）、现场验证（李青候以神识听村，当场拆穿谎话）、自我交代（「我怕死啊，修仙不是能长生么」）。不使用性格旁白。
- **世界观铺设方式**：第1章只给「修仙可以长生」这条凡人常识；第2章借「一路走一路看」的移动视点铺完宗门格局，用主角自己的失望情绪带走读者的陌生感。
- **黄金三章节奏**：第1章立人、第2章落脚、第3章入伙，形成一个完整的「进城—落户—被接纳」小循环，并在第3章末给出贯穿全书的行为准则（六句真言 + 「宁在火灶饿死，不去外门争锋」）。

## 早期可借鉴点

1. **用一场戏骗读者两次**：先按最熟悉的「温情送别」模板写，再用旁观者群体的反应翻转，成本极低、记忆点极强。
2. **主角动机的反常识化**：别人修仙求道、复仇、扬名，他只有一条「怕死」，动机越窄越好写，也越容易共情。
3. **先看见天堂再掉进泥坑**：第2章先用庭院、阁楼、仙鹤、秀美同门把期待抬满，再让向导一句「就在那」把他推到最破的草房。
4. **关键道具藏在杂物堆里**：数千口旧锅中挑中一口龟形锅，用一个不起眼的选择完成金手指投放，比开箱送宝更自然。
5. **口诀式设定最易传播**：六句真言既是设定也是金句，读者会自动记住并期待后续被应用。

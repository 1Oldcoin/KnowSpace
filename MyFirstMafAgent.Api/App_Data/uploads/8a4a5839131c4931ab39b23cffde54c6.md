## 第16章 心细入微

**概要**：白小纯躺在院中感到皮肤硬了一些，躺了大半个时辰酸软才消散，随即回木屋取出外门弟子所得的丹药与香药。他用龟纹锅与一色火木，把三粒丹药和一根青香各炼灵一次，服下后摆出紫气驭鼎功第四幅图修行，冲击凝气第四层时体内灵气枯竭，他向青香吐出一口灵气，青香自燃化青烟钻入七窍汗毛孔，灵气小河膨胀一倍，他因此突破凝气四层，体内逼出黑色污垢，木剑速度与肃杀之意都提升。侯云飞先前带他去万药阁取来的玉简内有一万种草木，是灵童必须掌握的第一篇，他凭一股狠劲把每一株都看到近乎入微的程度，一个月里边修行紫气驭鼎功第四层与不死长生功，边记药草。他因李青候所说宗门弟子每半年至少完成一件任务的规定，接了种植灵冬竹的任务，发现灵田灵气稀薄使种子生长缓慢，便把灵土放进龟纹锅炼灵，只用一色火木炼了表面一层，随后种下种子，绿芽快速长到三尺多高。夜里他记住全部一万种草木，还看出玉简图文对个别药草的介绍似有矛盾，打算第二天去换草木第二篇，又担心考核方式而反复温习。

**关键事件**：1.白小纯用龟纹锅炼灵三粒丹药与一根青香，突破凝气四层 2.白小纯凭狠劲把草木第一篇一万种药草记到入微程度 3.白小纯将灵土放入龟纹锅炼灵，种下灵冬竹种子使其快速生长 4.白小纯记住全部一万种草木，准备次日换取草木第二篇

**逐章写法公式**：

- **情绪流向**：起：躺院中察觉皮肤变硬，对成为药师更期待 → 承：炼灵丹药青香，冲击凝气四层 → 转：灵气枯竭时吐气点燃青香，突破成功 → 合：记住一万种草木，把灵土炼灵种下灵冬竹，担心次日考核
- **节奏配比**：慢铺垫 55% / 快冲突 20% / 爽点爆发 20% / 悬念留白 5%
- **本章结构公式**：小突破立竿见影（给即时回报） + 苦修细节层层加码（立人设） + 龟纹锅用在新对象上（打开新工具链） + 明日考核的未知（留钩子）
- **本章核心技巧**：把修行进度写成可数的动作与身体反应，再让主角用同一个旧道具解决一个全新的问题。
- **卡点与伏笔**：结尾卡点：未知型卡点，白小纯不知换取草木第二篇用什么方法考核，下章期待他能否通过考核；埋设/回收伏笔：龟纹锅能炼灵灵土 → 为后续灵田产出与资源漏洞埋线；灵冬竹三个月期限 → 为交任务的贡献点埋线；草木第一篇记到入微 → 为木屋考核的碾压埋线

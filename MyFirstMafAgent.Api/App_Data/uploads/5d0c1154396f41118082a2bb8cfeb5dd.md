## 第6章 灵气上头

**概要**：白小纯被许宝财操控木剑追杀，他背着一口大黑锅、穿着七八件皮袄一路跑回火灶房，张大胖出面拦下，许宝财甩出木剑将大树穿透出一个窟窿，放下狠话离去。白小纯回屋后担心一出火灶房就被堵住，取出紫气驭鼎功的竹书按第二幅图修行，从十息坚持到二十息、三十息，体内气脉小溪增加了一成；此后连续十五天不出房门，修行一个月时第二幅图突破到一百五十多息，又修一个月后突破凝气第二层，灵压扩散方圆十多丈。张大胖等人先是吃惊，后来打算悄悄去废掉许宝财。白小纯开门走出，跳上火灶房院子的篱笆墙，称许宝财是灵溪宗杂役里的绝世天骄、修为凝气二层，与自己势均力敌，说完回屋。黑三胖与黄二胖据此认为白小纯灵气上头、修疯了。

**关键事件**：1.白小纯被许宝财用木剑追杀，一路跑回火灶房，许宝财甩剑穿透大树后放下狠话离去 2.白小纯闭门苦修两个月，途中气脉小溪增加一成，最终突破凝气第二层 3.白小纯跳上篱笆墙自言自语，张大胖等人认为他灵气上头修疯了

**逐章写法公式**：

- **情绪流向**：起：被木剑追杀的惊惶 → 承：回房后的不安与两个月的苦修 → 转：突破凝气第二层 → 合：故作深沉的独白被当成修疯
- **节奏配比**：慢铺垫 45% / 快冲突 20% / 爽点爆发 20% / 悬念留白 15%
- **本章结构公式**：追杀逃命（危机引入） + 木剑穿透大树（威胁做成实物） + 两月苦修与突破（实力兑现） + 篱笆墙独白（喜剧错位）
- **本章核心技巧**：用对手的一次出手把威胁钉成实物，再用时间阶梯与可量化进度把苦修写成进度条，最后用配角的错误解读卸掉沉重感。
- **卡点与伏笔**：结尾卡点：喜剧卡点，白小纯只顾贬低自己的对手，实际危机未解，下章期待许宝财带人上门；埋设/回收伏笔：被木剑穿透的大树 → 威胁的量化凭证；许宝财有点小小背景 → 为监事房登场铺垫；紫气驭鼎功第二幅图 → 修为阶梯的计量工具

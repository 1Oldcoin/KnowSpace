## 第19章 白鼠狼的传说

**概要**：白小纯作为外门弟子在香云山过得滋润，只是院子偏僻、四周没有认识的人，偶尔连说话的都没有。此时秋风已走、风雪飘落，灵冬竹高度已超越他的身高。距他成为草木石碑第一已一个多月，草木第二篇难度超出预料，研究速度慢了一些，他一想到试炼结束时剩下没完整的残片就升起压力，暗自下决心不能让周心琪超越，好在他修行不死长生功已快要达到一个小周天。三天后的黄昏，天空飘起雪花，白小纯奔跑时身体猛地一震，持续九九八十一天的剧痛瞬间消失，阵阵热流凝聚在皮肤上使皮肤滚烫得像刚出炉的烙铁，雪花未落即融化成白气，皮肤出现黑色光芒并游走消散，手臂摸起来坚韧如牛皮，他一冲竟直接出现在数丈外，速度是之前的一倍多。随后他按口诀修行闭住口鼻、以身体呼吸的方法，要求每天九九八十一次、持续九九八十一天，练成后与剧痛的小周天结合便是不死皮的小成。他完成一个循环后身体肉眼可见瘦了一圈，完成第十五次呼吸时几乎皮包骨，饥饿感让他睁眼头昏眼花、眼睛发绿，冲出院子下山直奔火灶房，飞身而入抢走黄二胖面前的碗，自己拿起大锅连喝一百多口锅的米汤仍不觉撑，又盯着胖子师兄们咽唾沫，黄二胖大吼让九胖去厨房拿给周长老准备的灵食。白小纯按火灶房六句真言只吃边角，饥饿感稍减后离开，黄二胖拍着他的肩膀说以后多回来补补，他决定少回来以免哪天没忍住。上山路上他听到鸡鸣，身体一顿，四下看无人注意便没入草丛，蹲在香云山专门饲养灵禽之地的栅栏外，望着尾巴有三色羽毛、个头有小牛犊般大的鸡咽唾沫。

**关键事件**：1.白小纯完成不死长生功九九八十一天的小周天，剧痛消失、皮肤坚韧、速度翻倍 2.白小纯修行身体呼吸法后暴瘦并陷入极度饥饿 3.白小纯冲入火灶房连喝一百多口锅米汤，按六句真言只吃边角 4.白小纯听到鸡鸣，蹲在饲养灵禽处栅栏外觊觎鸡群

**逐章写法公式**：

- **情绪流向**：起：外门日子滋润却偏僻孤独 → 承：九九八十一天小周天成，剧痛消失速度快一倍 → 转：新呼吸法带来暴瘦与疯狂饥饿，冲进火灶房连喝米汤 → 合：被饥饿逼上山，听到鸡鸣蹲到灵禽栅栏外
- **节奏配比**：慢铺垫 35% / 快冲突 20% / 爽点爆发 20% / 悬念留白 25%
- **本章结构公式**：孤独日常与灵冬竹长势（做反差底色） + 八十一天苦修兑现（给第一波爽） + 新代价引发厨房闹剧（喜剧化失控） + 鸡鸣引出下一章目标（把胃口变成钩子）
- **本章核心技巧**：把长期苦修的回报当场兑成身体数据，同时立刻用一个新的生理代价把主角推向下一个尴尬又危险的目标。
- **卡点与伏笔**：结尾卡点：行动悬念型卡点，白小纯蹲在灵禽栅栏外盯着三色尾羽的鸡，下章期待他是否下手及后果；埋设/回收伏笔：不死长生功第二阶段的呼吸法与饿 → 为偷鸡长期化埋线；灵禽与三色尾羽 → 为三色火燃料埋线；火灶房六句真言 → 为后续维护火灶房师兄的情义线埋线

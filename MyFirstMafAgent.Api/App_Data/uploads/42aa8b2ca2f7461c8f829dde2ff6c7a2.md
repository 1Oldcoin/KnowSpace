## 第18章 引领气氛！

**概要**：周心琪在灵兽第四篇也就是第九石碑上取得第一位，万药阁四周外门弟子欢呼，说她必定开创前所未有之事，她微微一笑更引来热烈呼声，被看成香云山的门面。白小纯在人群里羡慕地看向草木第一篇石碑，发现上面代表自己的那只乌龟压在宝瓶之上，他拿出玉简一看，里面除第一篇一万草药外又多万，欣喜中准备听人欢呼，可四周注意力都在周心琪身上，他便尖细地喊出草木第一篇第一名换了人、那只好看的乌龟是谁画的，身边人纷纷看去并惊呼，议论声盖过了对周心琪的欢呼。周心琪听到惊呼转身看到乌龟，认为这第一是自己刚成外门弟子时拿下的、当时未用全力，说宗门出了一个好苗子，随即进入草木第一篇的木屋想把第一拿回来。白小纯自认应是第二并安慰自己，可一炷香后排名未变，周心琪用了至少八成造诣完整了四千株仍被压在下面，此后她一次次进入木屋，第二次用出全部造诣完成近乎六千株还是失败，天色渐晚、面色已苍白、双眼出现血丝，四周从哗然到寂静。白小纯忍着不承认，暗想以后要在万众瞩目处说出自己是草木石碑第一，随后摆出高手寂寞的样子远去。周心琪连续七天不断尝试，最好成绩达到七千株仍无法超越，最后目中首次出现黯淡，喃喃问对方是谁，咬牙不再挑战，而那只乌龟深深刻在她心底。

**关键事件**：1.周心琪在灵兽第四篇石碑取得第一位，白小纯发现自己的乌龟压在她名字上面 2.白小纯出声引导人群注意草木第一篇石碑，四周哗然 3.周心琪两次进入木屋挑战，用出全部造诣完成近乎六千株仍失败 4.周心琪连续七天尝试，最好到七千株仍无法超越，最终放弃并记住乌龟

**逐章写法公式**：

- **情绪流向**：起：周心琪九碑第一，白小纯在人群里羡慕 → 承：他发现自己第一，用一句大喊引来全场注意 → 转：周心琪两度挑战失败，四周由哗然转为寂静 → 合：七天连战仍不敌，周心琪放弃却记住乌龟，白小纯忍着不说
- **节奏配比**：慢铺垫 25% / 快冲突 30% / 爽点爆发 35% / 悬念留白 10%
- **本章结构公式**：对手登顶的最高潮（把场子做满） + 主角悄悄压过她（制造反差） + 主角自导自演的舆论引爆（把爽感放大） + 对手的七次失败与收尾执念（把爽感固定下来）
- **本章核心技巧**：把主角的胜利写成一件他没打算公开的事，再用一个他自己都不敢认领的疑问句，让全场替他把第一名喊出来。
- **卡点与伏笔**：结尾卡点：悬念型卡点，周心琪认为乌龟弟子身份成谜并深深刻在心底，下章期待身份何时揭晓；埋设/回收伏笔：白小纯要在万众瞩目处公开自己是乌龟药师 → 为后续公开场合埋伏笔；周心琪七天未能超越 → 为此后她与白小纯的纠葛埋线；乌龟传闻传遍香云山 → 为下一章白鼠狼的传说提供舆论场

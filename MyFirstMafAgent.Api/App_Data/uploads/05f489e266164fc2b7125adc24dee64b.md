## 第17章 小乌龟

**概要**：第二天清晨白小纯看到灵冬竹已长到半人多高，随后沿山路前往万药阁，走了半个多时辰，在太阳完全升起时看到万药阁十座数十丈高的青色石碑，碑上刻的是历代药师的独有印记而非姓名。他从碑上第一名宝瓶得知那代表周心琪，并回想此女出身平凡人家，数年前被宗门前辈察觉资质惊人引入宗门，是罕见的草木灵脉，拜入香云山成为李青候坐下唯一弟子，因门规从外门弟子做起，资源却按内门发放。白小纯绕碑一圈，发现十座石碑中周心琪有八座第一，其余两座没有她的名字。这天万药阁人山人海，外门弟子等周心琪来挑战灵兽第四篇；他先跟人一起喊周师姐加油，再向一名瘦弱外门弟子问清换草木第二篇要去石碑下的木屋考核，等人出来后才进屋。他盘膝坐上蒲团，把草木第一篇玉简碰触石碑使其融入，并按问到的方法画下代表未来药师的印记，画的是他喜欢的一只歪扭乌龟。手掌按上石碑后他进入虚幻空间，面前是铺天盖地、被斩成十多份并混淆的残破药草，冰冷声音宣布一炷香内拼凑灵株、以完整数量多少为考核。他先用指认的方式飞快拼成两株，随后连点不止，一路拼到一千株、三千株、七千株，眼中布满血丝、头顶冒白烟，最终残片所剩不多时全部光芒一闪消失，他回到木屋，忐忑地认为还差一些，捡起玉简垂头丧气走出木屋，抬头却见周心琪也恰好走出，她身后石碑上代表她的宝瓶已出现在第一位。

**关键事件**：1.白小纯到万药阁，从石碑印记得知周心琪的身份与八碑第一 2.白小纯问清换取草木第二篇需入木屋考核，并在石碑上画下乌龟印记 3.考核内容是一炷香内拼凑被斩断混淆的药草残片 4.白小纯拼出数千株药草后自觉还差一些，同时看到周心琪的宝瓶升至第一位

**逐章写法公式**：

- **情绪流向**：起：清晨见灵冬竹长高，动身去万药阁 → 承：从石碑印记得知周心琪的来历与战绩，人群等她挑战 → 转：进入木屋画乌龟，面对铺天盖地的残片考核 → 合：拼到数千株仍觉不够，出门时看到宝瓶已居第一位
- **节奏配比**：慢铺垫 45% / 快冲突 25% / 爽点爆发 20% / 悬念留白 10%
- **本章结构公式**：路上风景与灵冬竹长势（接上章成果） + 石碑与印记的世界规则（立参照系） + 周心琪身份的层层铺开（立对手） + 考核残片与乌龟印记（埋冲突并留悬念）
- **本章核心技巧**：先花大篇幅造一个所有人都服气的标杆，再让主角用一个可笑的符号悄悄站到标杆上面，但把结果压到章末只给一眼。
- **卡点与伏笔**：结尾卡点：误判型卡点，白小纯自觉还差一些，读者与他同时不知名次，下章期待第一到底是谁；埋设/回收伏笔：乌龟印记 → 成为香云山传闻的源头与后续身份公开的钩子；药师印记代表荣耀 → 为乌龟压宝瓶的画面提供讽刺与爽感；张大口问询的瘦弱外门弟子 → 功能角色提供考核方法

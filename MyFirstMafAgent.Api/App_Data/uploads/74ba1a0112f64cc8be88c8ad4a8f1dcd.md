## 第15章 不死长生功！

**概要**：白小纯成为外门弟子后住进香云山东侧中断一条岔开山路尽头的院子，院子约一亩地大小，四周草木花香，院里有木屋与开垦的田地、角落有一口井，木屋内桌椅床木由深紫色木头制成并散出檀香，远不是杂役区可比；他抬头看向香云山山顶，想着以前听大师兄说起成为内门弟子就可以住洞府，整个香云山只有内门弟子有资格居住在山峰上半段。他伸懒腰拿出储物袋拍了一下，取出写着凝灵的丹瓶与刻着升青的青香，想到当初做杂役时也获得过类似之物、吞下后修为增加，丹药与香的效果一样；他觉得直接吞下浪费，打算炼灵后再用，但眼下没有一色火的木头，准备白天下山去弄。随后他盘膝打坐修炼，为长生而修，对修行颇有执着。一夜无话，清晨他穿上外门弟子的衣衫，按昨天候师兄交代的位置去藏经阁；藏经阁在山的另一面，走了半个时辰才远远看到高高的塔楼、光芒流转、有威压散出笼罩八方。途中遇到的外门弟子大都行色匆匆，察觉他凝气三层的修为后直接无视，他遇到的弟子修为都在他之上，还有几人给他深不可测之感；接近藏经阁时人更多，一道长虹从远处山峰飞来绕着香云山转一圈后直奔天边，虹内青年脚下踏着一个轮子，旁人议论说是执法堂的钱大金、内门弟子、据说已到凝气第八层大圆满、可以短时间借助法宝飞行。白小纯进塔楼第一层把身份令牌放在案几上，光蕴一闪后上到第二层，见众多架子放着一排排玉简与竹书；他刚要走上一层楼梯就被光幕弹回，一旁一字眉青年说那里是凝气五层才可以去的。他在第二层翻看玉简与竹书，觉得每一个都很心动，尤其是一门火道术法，随后找到紫气驭鼎功的玉简，内含第四层到第八层的图案与口诀；快到黄昏时他走完第二层七成区域，随手拿起一本残破竹书，看到不死长生功后睁大眼睛，读出这是炼体功法、若大成似乎可以不死长生，他决定选择这门功法。一层老者睁眼扫他，目光让他身体一震，老者说新晋弟子可以拓印一份紫气驭鼎功前八层、还可额外选择一门功法，随后皱眉提醒这不死长生功只有残篇、修行难度极大、剧痛非常人能忍、以往弟子很少有人修行成功、大都放弃，问他是否确定，白小纯说非常确定，老者拓印后落在白小纯面前，他便收起玉简回院子。木屋内他运转灵气融入玉简，半个时辰后睁眼，知道此功分内外两炼，外炼为皮、肉、筋，内炼为骨与血，残篇只有皮的修炼之法，另外功法提到修行消耗极大并介绍了碎喉锁等秘法、说碎喉锁无坚不摧；他按功法要求双手拍打全身，拍了整整一夜，第二天全身刺痛，站也不是坐也不是，手臂抬起都剧痛难忍。他念着功法里先松在紧、紧了再松的话在院子里蹦跳惨叫，带灵石下山去买药草换延年益寿丹，一路被不少外门弟子诧异注视；他在坊市买了足够的草药，又买了一些一色火的木头，二色火的木头价格很高、他买下一块口袋就空了，随后去任务处完成杂役时接下的任务换来一枚延年益寿丹。这丹有拇指盖大小、通体黄色、散出奇异香气，他已痛得说不出话、汗珠不断流下浸透身体，一步步爬着香云山台阶回院子，不少外门弟子露出诧异或嫌弃的神情，夜深夜入院子后直接倒下痛得昏迷，昏迷中仍痛醒几次，天亮睁眼时全身痛处才全部消失。按功法介绍，这样的一天一夜且不能昏迷才算一个完整的小循环，需要九九八十一次才算一个小周天、如同在改造皮肤，之后皮肤有了一定韧度就不会这么剧痛。他趁身体不痛取出延年益寿丹，四下确认无人后回木屋掐诀唤出龟纹锅，点燃二色火的木头，木头发急速燃烧成灰烬、龟纹锅上两道纹亮起；他把延年益寿丹放入锅内，银芒刺目闪耀后消失，丹药上多了两道银纹、药香比之前浓郁得多，他可惜找不到三色火的燃料，随后把灵药扔入口中。灵药入口即化，滚烫热流在体内扩散，他脑海轰的一声、身体如同火炉燃烧，额头那根白头发肉眼可见化作黑色，体内有种生机被补充的感觉，半晌后感觉更强、鼻孔流下鼻血；他修行紫气驭鼎功却没有太多用处，因为灵药补的不是灵气而是元气，鼻血越流越多、体内热流膨胀，他觉得自己像一个就要炸开的皮球。危机关头他想起不死长生功，跳起来用全部力气飞快拍打全身，拍打后体内热流出现疏导之感，过了半个时辰热流才完全消散，他全身酸软倒下喘着粗气，但精神前所未有的好。这枚灵药被炼灵两次后效果远超之前、价值超出太多，以他凝气三层的修为根本无法承受。他由此想到灵药有的可以增加灵气、有的可以增加寿元，猜到可能有一种药可以让人长生，又想到香云山就是培养药师的，于是决定要成为药师、炼制出一枚长生不老丹。

**关键事件**：1.白小纯入住香云山外门弟子的院子，取出凝灵丹瓶与升青香，决定炼灵后再用 2.白小纯赴藏经阁，途中见到执法堂内门弟子钱大金飞行，得知三层需凝气五层 3.白小纯在第二层找到紫气驭鼎功第四到第八层并选中残篇不死长生功 4.藏经阁老者告知不死长生功只有残篇、修行剧痛、少有人成功，白小纯仍确定选择 5.白小纯拍打全身一夜，按功法活动身躯并下山买草药与一色火木头，买下一块二色火木头后口袋变空 6.白小纯完成杂役时接下的任务换来延年益寿丹，痛得汗透身体回院子昏迷一夜 7.白小纯趁身体不痛用龟纹锅炼灵延年益寿丹，得到两道银纹的丹药 8.白小纯服下炼灵两次的延年益寿丹后元气过盛、鼻血不止，靠不死长生功拍打疏导热流 9.白小纯决定成为药师、炼制长生不老丹

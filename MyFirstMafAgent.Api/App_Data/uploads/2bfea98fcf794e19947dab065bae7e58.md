## 第7章 龟纹认主

**概要**：白小纯在屋舍内忍痛练紫气驭鼎功第三幅图，全身刺痛后不得不放弃。他取出藏起来的炼灵一次的灵米煮熟吞下，半个月后的深夜突破凝气第三层，体内气脉由溪流变成小河。因经脉膨胀需适应，他压下再弄灵米的念头，又因忌惮许宝财的木剑，决定把木剑炼灵两次。他用一色火的灵木尝试多次无反应，判断温度不够；换用紫色木头点燃二色火后，龟纹锅第二道灵纹亮起。木剑入锅后银光暴涨直奔白小纯，一股冰寒抽走他体内某物，剑身随后出现第二道银纹，灵溪宗南岸天空响起雷声。他照铜镜发现发梢多出一根白头发，认定被抽走的是寿命；他随后发现与龟纹锅有了联系，指锅可收入指尖，再指地面锅又出现。第二天午后他察觉七八道身影疾驰而来，当首是许宝财。

**关键事件**：1.白小纯吞下炼灵一次的灵米，半个月后突破凝气第三层 2.白小纯用二色火点亮龟纹锅第二道灵纹，炼灵木剑时被抽走一年寿元，木剑生出第二道银纹 3.白小纯发现自己可把龟纹锅收入指尖，第二天许宝财带七八人上门

**逐章写法公式**：

- **情绪流向**：起：强行修行的剧痛与放弃 → 承：吞灵米突破凝气第三层的狂喜 → 转：炼灵抽走一年寿元的失魂 → 合：察觉许宝财带人上门
- **节奏配比**：慢铺垫 35% / 快冲突 10% / 爽点爆发 25% / 悬念留白 30%
- **本章结构公式**：第三幅图苦修（体能逼到极限） + 炼灵灵米突破（小爽点兑现） + 二色火炼剑抽寿（代价揭示） + 收锅认主与许宝财上门（能力与危机同章落地）
- **本章核心技巧**：先给一次成功突破，再让新道具在同一章索取代价，并立刻给出补偿性能力，最后用旧对手的回场封住章节。
- **卡点与伏笔**：结尾卡点：危机卡点，许宝财带着七八人和自己的师兄上门，下章期待正面斗法；埋设/回收伏笔：炼灵一次的灵米 → 修为跳级的燃料；龟纹锅第二道灵纹 → 炼灵上限提升；被抽走的一年寿元 → 后续寻找延年益寿丹的动机

## 第10章 师兄别走

**概要**：白小纯向张大胖等人说明，宗门每月开启试炼且每峰只取最快走完的前三，他与师兄们都是凝气三层，张大胖与黑三胖更是三层巅峰，因此可抢先占据前三名再把名额卖给后面的人。众人叫好，决定下个月动手。试炼之日清晨，火灶房九人分守三处，带三口大黑锅最先到达三座山峰试炼入口。执事宣布开始后，三人先后冲上台阶。香云峰试炼之路上威压让三人慢下来，白小纯想到延年益寿丹而灵气扩散加速，黑三胖与张大胖也各自加速追上。一炷香后白小纯先到山顶，在出口前一步停下喊停，三人坐在出口处拒领外门弟子名额。又过一炷香，一个第九次参加试炼的马脸杂役到来，正要放弃时，白小纯起身喊他别走并提出把名额给他。

**关键事件**：1.白小纯提出抢占试炼前三名再把名额卖给后面的人，火灶房众人决定动手 2.试炼之日火灶房九人分守三座山峰并率先登顶，坐在出口处不肯成为外门弟子 3.白小纯向第九次参加试炼的马脸杂役兜售外门弟子名额

**逐章写法公式**：

- **情绪流向**：起：白小纯抛出损招 → 承：众人拍板与一个月准备 → 转：三峰抢跑与绝尘登顶 → 合：堵门不领名额，改做名额买卖
- **节奏配比**：慢铺垫 30% / 快冲突 15% / 爽点爆发 35% / 悬念留白 20%
- **本章结构公式**：方案揭晓（规则翻面） + 一月准备（蓄势） + 三峰抢跑登顶（爽点兑现） + 堵门卖名额（反转收束）
- **本章核心技巧**：先把制度规则完整摊开，再让主角只在规则内换一种用法，用三座山峰的同步行动放大执行规模，最后把爽点从赢变成不领。
- **卡点与伏笔**：结尾卡点：交易卡点，白小纯刚开口兜售名额，下章期待第一笔生意的成交价与后续连锁反应；埋设/回收伏笔：张大胖与黑三胖压制修为不愿离开火灶房 → 本章抢名额的实力基础；监事房与火灶房的钱财矛盾 → 赚钱动机；延年益寿丹 → 白小纯在试炼之路上加速的个人动机

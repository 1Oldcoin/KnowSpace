## 第14章 三师兄？三师姐？

**概要**：看到白小纯被卷上山顶，陈飞三人立刻幸灾乐祸，两个负责此地的外门弟子也露出解恨神情。白小纯落地后惨叫说我不去啊，声音里的委屈足以让闻者流泪；试炼之路上的张大胖与黑三胖看到李青候后哆嗦低头，想趁其不注意逃掉，李青候却对二人也说还有你们两、也来吧，一股吸力卷着张大胖与黑三胖拽到山顶，张大胖惨叫说宁在火灶房饿死、不去外门争锋，比白小纯还凄惨。李青候喝斥闭嘴，白小纯立刻起身、神色肃然凝重，身上看不出委屈，张大胖也赶紧起身。李青候随即宣布：张大海去紫鼎山成为外门弟子，陈轻柔去青峰山，白小纯留在香云山成为此山外门弟子并跟他走；他心里只是闭了一次关，出来后就听到宗门内关于火灶房等人的事情，此事已传入宗门长老那里，长老们觉得这是修行时难得的乐趣、没有想惩罚，李青候觉得这么下去不好才来到这里。白小纯与张大胖、黑三胖告别时忽然想起什么，古怪地问三师兄的大名是不是陈轻柔，并说听起来像绝世美女；黑三胖哼一声转身下山。白小纯问张大胖他怎么了，张大胖拍着他的肩膀说从来没说过黑三胖是他的师兄，实际上她是他的师姐，说完赶紧跑开，白小纯呆呆站着如五雷轰顶，正要去看黑三胖的背影，李青候冰冷地说啰里啰嗦还不跟上来。白小纯跟着李青候三步一回头望着山下的火灶房；他早就打探出李青候是灵溪宗南岸三山之一香云山的掌座，位高权重。香云山内部鸟语花香如仙境，比从外面看大数倍，试炼之路出口山顶只是分支山头、相当于山脚，山中云雾缭绕带有药香，白小纯大口呼吸后数月不曾精进的凝气三层修为活跃了不少；李青候对白小纯一年多的修行速度觉得尚可，交代他成为外门弟子后不可再胡闹，修行如逆水行舟要时刻自勉，又说宗门资源只是一方面，还需自身勤奋与机缘，让他稍后去看宗门任务并选一些磨练。白小纯想到门规规定外门弟子每隔一段时间至少完成一件任务，未完成会被收回身份贬回杂役，心中惊喜；李青候似能猜到他的心思，说旁人未完成会贬回杂役，他若懒惰将被逐出宗门、送回村子，百年之后李青候若想起会去为他上根香，白小纯保证主动完成任务。香云山中段云雾间有一处阁楼，青年候云飞在里面看书，见李青候便起身拜见，李青候让候云飞带白小纯办理外门弟子身份后化作长虹直奔山顶。候云飞认出白小纯就是堵住香云山试炼之路贩卖名额的人并笑了，带他走在香云山介绍各处，说香云山在宗门南岸地位超然，青峰山擅剑修、紫鼎山擅术法，香云山擅长炼制灵药，即便在通天河支脉上四大宗门中香云山也声名赫赫，掌座是整个东林洲仅有的两位药师之一；成为香云山外门弟子即为灵童，需学习草木知识与炼药之法。候云飞带白小纯领取外门弟子的衣衫与物品，还有一个储物袋，空间很小但白小纯如获至宝；成为外门弟子后宗门奖励二十块灵石，这让白小纯买草药的灵石数立刻够了。至黄昏，候云飞介绍万药阁并让他取一枚玉简，说玉简内有一万种草木需要牢牢记住才能换取第二枚，又讲修行之路漫长、灵药是不可缺少的助力，若能成为药师可平步青云，灵童、药徒、药师能走到哪一步看造化。傍晚候云飞把白小纯送到宗门安排的院子，说明天要下山不陪他去藏经阁，让他清晨过去取紫气驭鼎功的后几层口诀，还可额外选择一门功法，这是每个外门弟子只有一次的挑选机会，之后要花费贡献点；候云飞自称候云飞并感谢白小纯当日对舍妹的照顾后离去。白小纯想到侯小妹，颇有无心插柳柳成荫之感，许久后深吸口气看着自己的院子，目中露出朝气，小袖一甩走入院子，说外门弟子似乎看起来也不错。

**关键事件**：1.李青候把白小纯、张大胖、黑三胖三人一并卷上山顶 2.李青候宣布张大海去紫鼎山、陈轻柔去青峰山、白小纯留在香云山成为外门弟子 3.白小纯得知黑三胖本名陈轻柔且实际是师姐 4.李青候交代修行与任务要求，并用逐出宗门、送回村子警告白小纯 5.候云飞带白小纯办理外门弟子身份、介绍香云山与万药阁，白小纯获得二十块灵石奖励与一枚储物袋 6.候云飞说明次日藏经阁取紫气驭鼎功口诀并可额外选一门功法

**逐章写法公式**：

- **情绪流向**：起：白小纯落地惨叫、陈飞等人幸灾乐祸 → 承：三人被一并卷上山顶、李青候分派去处 → 转：陈轻柔三个字揭开黑三胖是师姐，白小纯五雷轰顶 → 合：候云飞办完身份并揭开兄妹关系，白小纯对院子生出朝气

## 第8章 我和你拼了！

**概要**：许宝财带监事房七八人找上门，白小纯本打算等到凝气第四层才保险，见躲不过便穿上七八件皮袄、背起煮灵米的备用锅走出房门。张大胖等人拎着菜刀大勺在火灶房门前与监事房众人对峙，监事房的人袖口有监字，其中一个大汉散出凝气三层灵压。许宝财看到白小纯后冲出，白小纯大喊一声把全部灵气注入木剑，木剑上两道银纹一闪、剑身膨胀一圈，撞碎许宝财的木剑，又刺穿大树把树放倒，许宝财右臂鲜血飞溅。监事房大汉认出这是以灵化锋、举重若轻的神通。白小纯大笑后追打许宝财，许宝财认定白小纯本来就有大来头、只是装弱，气恼之下昏了过去。监事房大汉说他藏得深，抱拳后带人把许宝财拎走，张大胖拍肩夸他，白小纯得意抬头。

**关键事件**：1.许宝财带监事房七八人到火灶房，与张大胖等人对峙 2.白小纯全力御剑击碎许宝财的木剑并放倒大树，伤了许宝财的右臂 3.白小纯追打许宝财致其昏迷，监事房大汉带人离去

**逐章写法公式**：

- **情绪流向**：起：被堵门的迟疑与咬牙硬拼 → 承：一剑碎剑断树的爆发 → 转：许宝财的荒唐误判与昏迷 → 合：监事房退走、师兄弟笑闹
- **节奏配比**：慢铺垫 25% / 快冲突 30% / 爽点爆发 35% / 悬念留白 10%
- **本章结构公式**：全副武装出门（紧张起手） + 两方对峙（势力展示） + 全力一剑（爽点爆发） + 追打与误判（喜剧收束）
- **本章核心技巧**：把前两章攒下的修行成果压缩进一次出手，用三层围观者的反应给威力定价，再用反派的错误归因把胜利变成笑点。
- **卡点与伏笔**：结尾卡点：轻松卡点，白小纯用高手寂寞的样子掩饰兴奋，监事房只是暂退，下章期待他的修行成果被别人重新评估；埋设/回收伏笔：举重若轻的神通 → 后续被宗门注意的引线；监事房大汉的小旗与雾气 → 监事房手段的后续展示；白小纯背着的备用锅 → 火灶房道具与战斗准备的呼应

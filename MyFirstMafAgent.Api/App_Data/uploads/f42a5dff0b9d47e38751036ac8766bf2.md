## 一、概要

**总字数（前 20 章）**：约 6.3 万字 | **本切片章数**：20 章 | **全书章数**：1311 章 | **题材**：仙侠 / 修真（轻松搞笑底色 + 长生主题）

### 首版概要

帽儿山少年白小纯被全村人「欢送」出村修仙，村里人巴不得这个被唤作「白鼠狼」的麻烦精早点离开。他被灵溪宗修士李青候带走，投入第三峰杂役区，因资质与名额问题被塞进「火灶房」，成了背黑锅的九师弟，与张大胖等一群胖师兄以吃食结缘。他真正修仙的动机只有一条：想长生、怕死。捡到一口龟纹锅后，他意外走上「炼灵」之路，并先后与许宝财结仇、与侯小妹相识、三探不死长生功。前 20 章的驱动是「一个怕死的小人物在宗门底层的生存式成长」，笑点、贪吃与小心机是他的外衣，长生执念是内核。

### 全书概要（前 20 章 plot-aware）

白小纯是帽儿山下村庄的孤儿，父母早亡，留下一根祖传黑香——据说祖上救过一名落魄仙人，仙人许诺收白家血脉一人为弟子，点香即来。他三年里点了十二次香，每次都被雷声吓退，第十三次终于引来灵溪宗香云山掌座李青候。李青候以神识听出全村正在敲锣打鼓庆祝「白鼠狼」离开，当场拆穿他「舍不得乡亲」的谎话，白小纯如实交代：「我怕死啊，修仙不是能长生么。」就凭这一句执念，他被带进灵溪宗。

入宗后他因顶掉了许宝财攒七年灵石换来的名额，被塞进全宗最不受待见的火灶房做杂役。火灶房表面是废柴收容所，实际是隐藏的肥缺：师兄们修为早够外门却故意藏拙，对联写着「宁在火灶饿死，不去外门争锋」，还传他「灵株吃边角、主杆不能碰」等六句真言。白小纯在数千口旧锅中选中一口龟形锅，发现它能把灵米「炼灵」出银纹，吃下后修行一日千里——「炼灵」是替天道为物品强行注入天地之力的手段，可叠加，成功十次可生开天之变，代价是失败即废、且每一次成功都要从使用者身上抽走代价。他用二色火炼灵木剑第二次时，被抽走一年寿元，额头发梢多出一根白发。

为补回寿元，他接下寻找青灵叶、地龙果、石虫皮的任务换取延年益寿丹（该丹只能增一年寿元、限凝气五层以下、只第一次有效）。三味药材两条路皆断，他转而利用「各峰试炼之路每月开启、只取最快前三名」的规则，带着火灶房师兄占满三座山峰的前三名，把外门弟子名额卖给后面的杂役，靠这门灰色生意攒够了钱，也把监事房的陈飞彻底得罪。

在此期间他拼命修行：两个月突破凝气二层，服炼灵灵米后半月冲上凝气三层，用炼灵两次的木剑一剑击碎许宝财的木剑并将其打成重伤。第13章他把陈飞三人推上试炼之路山顶，逼其升为外门弟子，自己也因此被李青候点名收入香云山。第14-15章，他成了香云山外门弟子（灵童），领到储物袋、二十块灵石，并在藏经阁选定《不死长生功》残篇——这门功力大无穷但要承受「一天一夜不能昏迷才算一个小循环、九九八十一次才算一个小周天」的剧痛。他还把延年益寿丹炼灵两次服下，白发转黑，却因药力远超承受上限差点自爆，靠不死长生功的拍打疏导化险；此役之后他立下全书目标：要成为药师，亲手炼出一枚长生不老丹。

第16-20章是三条线并进：修为上他突破凝气四层并把炼灵用到灵土上；学问上他用一个月把万药阁一万种草木研究到绒毛小孔的程度；名声上他在万药阁石碑随手画下的「乌龟」压过了香云山天骄周心琪的宝瓶印记——周心琪连战三天、七天内最好成绩七千株仍不能超越，从此「神秘乌龟弟子」传遍香云山，而他忍着不认领，把认领写成未来的目标。同期不死长生功进入体呼吸阶段，代价从「痛」变成无底洞的「饿」，他靠小时候跟爹学的竹知了机关夜夜偷香云山掌座私养的灵尾鸡充饥，一个月偷走数十只，李青候已知晓却因外出未理会，饲养弟子咬牙切齿却查不出声息。第20章末，他把草木第二篇研究透彻，带着「要让所有人知道我就是骑在周心琪上面的龟爷」的期待直奔万药阁。

### 黄金三章评分

| 维度 | 评分 | 说明 |
|------|------|------|
| 开篇钩子 | 5 | 用一场温情送别骗读者一次，再用村民转身欢呼骗第二次，20 行内完成两次认知翻转 |
| 主角塑造 | 5 | 不给旁白定性，全靠「谎话被神识拆穿」与「我怕死啊」两场对话立住表里反差 |
| 爽点设计 | 4 | 前 3 章无战斗，爽点靠喜剧反差与「碗底加厚」的智力优越；强度中上、密度高 |
| 世界观铺设 | 4 | 第2章一口气铺完灵溪宗格局、内外门等级、各峰分工，信息密度约翻倍但不显说明感 |
| 章尾悬念 | 5 | 三次收尾分别落在新场景（灵溪宗）、新敌人（许宝财叫阵）、新准则（六句真言） |

### 三章各自功能

| 章 | 功能 | 核心事件 | 可借鉴要素 |
|----|------|----------|------------|
| 第1章 | 立人设 + 拉动机 | 全村欢送 → 谎言被拆 → 被带走 | 用一场戏骗读者两次；把主角动机窄化为「怕死」 |
| 第2章 | 落地图 + 埋金手指 | 进火灶房 → 选中龟纹锅 | 先看见天堂再掉进泥坑；关键道具藏在杂物堆里 |
| 第3章 | 结关系 + 给准则 | 血书叫阵 → 分食灵芝 → 碗底献策 | 冲突不靠打斗化解；把「被接纳」做成解谜；口诀式设定最易传播 |

### 开篇判断

- **开篇钩子类型**：反差钩。先按读者最熟悉的「留守儿童励志修仙」模板写，再让全村人的眼泪变成「终于送走祸害」的喜极而泣。
- **主角立人设手法**：他人评价（「白鼠狼」「为村子立下大功」）+ 现场验证（李青候神识听村）+ 自我交代（「我怕死啊」）三重叠加，不用一句性格旁白。
- **世界观铺设方式**：第1章只给「修仙可以长生」这条凡人常识；第2章借「一路走一路看」的移动视点铺完宗门格局，用白小纯的失望情绪带走读者的陌生感。
- **黄金三章节奏**：第1章立人、第2章落脚、第3章入伙，三章形成一个完整的「进城—落户—被接纳」小循环，并在第3章末给出贯穿全书的行为准则。

### 是否值得全量拆解 — 建议

**建议重点拆解第 2-20 章**：黄金三章质量高于同题材平均线，但本书真正的结构性亮点在「低位生态位 + 代价加码」的长线设计——第4-20章展示了同一套金手指如何被越界使用五次、每次如何配套一笔新代价，这对写长篇前 20 章节拍最有参考价值。

### 第1章 他叫白小纯

**概要**：帽儿山下村庄的乡亲在清晨为十五六岁的白小纯送别，白小纯说要去修仙却舍不得众人，头发花白的老者劝他走出村子就不要回来。白小纯走远后，村民立刻由难舍转为喜悦，敲锣打鼓，说出白鼠狼终于走了，并谢那个告诉他附近有仙人的人，历数他唆使孩子把全村的鸡吃光的事。白小纯听到锣鼓声，脚步一顿，沿山路上了帽儿山。行囊里有四把斧头、六把柴刀和一根黑香，他凭此吓退灌林中的哗哗声。这根香是爹娘去世前留给他的，据说祖上救过落魄仙人，仙人留香许诺收白家一人为弟子；三年里他点过十二次，每次都雷鸣闪电而不见仙人，他怕死便吐唾沫把香熄灭。这次是第十三次，香已只剩指甲盖大小。远处天空李青候乘长虹而来，他三年前察觉有人点燃自己凝气时送出的香药，三年来气息出现十多次又中断，被折腾了三年。李青候落到山顶挥手熄灭香，自称本座李青候，问白家后人为何点一根香点了三年。白小纯先说舍不得乡亲，李青候神识扫过山下，听到敲锣打鼓和欢呼白鼠狼离去，面色难看。白小纯改口说怕死，修仙能长生，所以想长生。李青候觉他执念可嘉，大袖一甩带他飞走，答所去之处为灵溪宗。

**关键事件**：1.村民送别白小纯，白小纯走远后村民敲锣打鼓庆祝 2.白小纯上山被灌林声吓到，拿出斧头柴刀和黑香 3.白小纯第十三次点燃祖传香，雷电大作 4.李青候现身熄灭香，追问点香三年的原因 5.李青候用神识听到山下欢呼，白小纯改口说怕死想长生 6.李青候带白小纯飞往灵溪宗

**逐章写法公式**：

- **情绪流向**：起：看似温情送别，实则全村送瘟神 → 承：山上遇险，掏出武器与祖传香 → 转：十三次点香惊雷，仙人真的降临并追问 → 合：白小纯改口认怂，被卷上天带走
- **节奏配比**：慢铺垫 35% / 快冲突 15% / 爽点爆发 25% / 悬念留白 25%
- **本章结构公式**：送别场景建立反差人设（铺垫） + 山林遇险展示装备与怕死（行动） + 点香引发天地异象（信息揭示） + 仙人现身与神识拆穿（转折点）
- **本章核心技巧**：用两套相反的反应对待同一件离开的事，让人物的乖巧外表与坏水内心同时成立
- **卡点与伏笔**：结尾卡点：信息类卡点，主角被带上天却只听到灵溪宗三个字，下章期待看到仙门全貌与他如何立足；埋设/回收伏笔：祖传黑香与白家祖上救仙人的旧人情 → 引出李青候与白家血脉的入门资格；白小纯点香十二次的记录 → 为李青候三年奔波提供原因

### 第2章 火灶房

**概要**：李青候带着白小纯飞抵灵溪宗南岸，没入第三峰下的杂役区域。灵溪宗位于东林洲通天河下游支脉，立足通天河南北两岸，已有万年历史，八座山峰横在通天河上，北岸四座、南岸三座，中间通天河上另有一座最磅礴的山峰，此山从中段起白雪皑皑。杂役处大石旁的麻脸女子起身拜见李青候，李青候留下一句将此子送火灶房去便化虹远去。麻脸女子给白小纯一个宗门杂役的布袋，带他一路走过庭院阁楼与青石路，白小纯看到美景和秀美女子，喜欢得不得了；走到一处七层晶莹阁楼前，麻脸女子指了旁侧小路，小路上地面碎裂、草房破烂、有怪味飘出，白小纯抱着最后希望问是否指错，得到否定回答。小路上几口大黑锅窜来窜去，锅下都是胖子，最胖的张大胖拎着大勺跑向麻脸女子，说喜鹊叫、要与她结成道侣，麻脸女子面色难看，交代人已带到便告辞。张大胖说白小纯能挤掉原本安排好的许宝财，按排行叫他白九胖，并讲火灶房有背锅的传统，锅中之王是铁精打造、刻着地火阵法。白小纯在数千口旧锅中选中一口椭圆形、像龟壳的锅，因自幼喜欢乌龟，认为长寿吉利。夜里他在草屋内看到锅背有几十条黯淡纹路，把锅放在灶上时锅上有一道紫光一闪而逝。他从布袋里取出丹药、木剑、燃香、衣服令牌和竹书，竹书上是紫气驭鼎功凝气篇，修行分凝气与筑基两个境界，功法共十层对应凝气十层，竹书只记前三层。他照第一幅图修炼，只坚持三个呼吸就全身酸痛惨叫，到傍晚仍未感到体内有气；原文交代即便资质绝佳之人，无外力单修第一层也需至少一个月。此时门外传来吵闹，面黄肌瘦的许宝财站在院门外，喊是谁顶替了他的名额。

### 第15章 不死长生功！

## 七、情绪模块与可复现套路

> 权威索引见 `剧情/情绪模块.md`。

### 情绪引擎

```
怕死（缺口） → 找保命手段（行动） → 拿到并验证（小爽）
                                  ↓
                       代价出现（寿元/剧痛/饥饿）
                                  ↓
                       用新手段填坑（再行动） → 新的、更离谱的越界使用
```

**核心**：本书把「爽」和「代价」绑在同一条链上。主角每变强一次就欠一笔账，下一段剧情自然有驱动力。

### 读者需求

| 需求 | 满足方式 | 代表章节 |
|------|----------|----------|
| 安全感的代偿 | 主角极度怕死，读者跟着他把「活下来」当第一目标 | 1、5、6 |
| 小人物的聪明 | 不靠硬实力，靠信息、规则、嘴皮子赢 | 3、12 |
| 笑点密集的无害坏 | 坏的都对外，对内有底线（六句真言） | 1、11、19 |
| 低成本代入的成长 | 提速靠「吃」和「工具」，不靠天赋苦修 | 4、6、20 |
| 延迟认领的期待感 | 已是第一却忍着不认，把认领写成未来目标 | 18 |

### 八张可复现模块卡

| 编号 | 模块名 | 适用 | 对照章节 |
|------|--------|------|----------|

| EM-002 | 落差交付新地图 | 新据点/新地图的第一印象 | 2 |

每张卡的具体结构、可替换项与情绪逻辑见 `剧情/情绪模块.md`。

### 重组与复现六条

1. 先定一个**窄到只有一个字**的动机（本书是「活」）。
2. 把据点写成**反差生态位**：外人看不起、内人抢着进。
3. 让**工具越界**，而不是不断发新外挂：一个金手指 + 五种用法，比五个金手指更好记。
4. 每次爽完**立刻记一笔账**：代价不必立刻要命，但必须留在账上。
5. 把主角的**「认领时刻」往后推**：这是把一次爽点摊成好几章的廉价办法。
6. 违规行为写成**技术流程，并保留底线**：给他一条自己不肯破的规矩。

### 势力：灵溪宗

- 位于**东林洲**内，属**通天河**下游支脉，立足通天河南北两岸，已有**万年**历史。
- 「八座云雾缭绕的惊天山峰，横在通天河上」：**北岸四峰、南岸三山**；中间通天河上另有一座最雄伟的山峰，下半部山体被掏空，金色河水穿胸而过。

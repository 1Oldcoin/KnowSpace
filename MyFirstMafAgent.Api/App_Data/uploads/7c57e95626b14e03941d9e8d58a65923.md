## 第4章 炼灵

**概要**：众人对白小纯的碗底加厚主意大喜，张大胖做主奖励他一粒灵米并塞进他手中。白小纯迷迷糊糊回房，还没上床体内积累的无数天才地宝灵气就爆发，脑袋一晕倒在地上呼呼大睡。第二天清晨他精神振奋，发现自己胖了一圈，全身黏糊糊地贴着一层黑色污垢，赶紧出去清洗。张大胖告诉他那些污垢是体内杂质，去掉后修行会顺利很多，这几天不用他帮手，并提醒灵米要快点吃。白小纯回房把那口龟形锅扛出去刷洗后放回灶上，把灵米拿在手中看了看，此米小拇指大小、晶莹光滑、散出香气。他点燃灶内几块木头，火焰燃烧后，龟形锅上第一条纹路由下向上亮起。他把灵米扔进锅中，坐在一旁按紫气驭鼎功第一幅图修炼，发现原本困难的姿势变得顺畅，没有窒息感，坚持到七八个呼吸也没有酸痛。坚持到三十息时，他体内出现一缕冰凉的气，飞速游走但没完整绕一圈就消散。他狂喜，认为这是昨晚吃下天材地宝的缘故。再修一次时，他坚持到六十息，体内滋生出一股比之前大一倍的气脉，如涓流般游走；按图上标示的路线行气，全身各处钻出的凉气融入气脉，最终化作小溪完整游走一圈，他脑海轰的一声，全身轻灵，污垢从汗毛孔泌出，那条小溪没有消散而是自行缓慢游走全身。他确认气脉常在就是修成第一层、达到凝气第一层。张大胖等人看到后露出彼此都懂的笑容。白小纯按竹书方法双手掐印指向桌子，刚连接的无形丝线立刻碎裂，他面色微微苍白；改用木剑后，木剑漂浮升起一寸就掉下，反复尝试后能升到十寸、二十寸、三十寸，到黄昏时已能直线漂浮，速度不快、难以转弯，但不会轻易摔落。他去查看锅中的灵米，发现灵米上出现一道刺目的银纹，渐渐成为暗银色，有种摄人心神之感；灶内的火已熄灭，木头成为灰烬，锅上那条亮纹重新黯淡。他认出灵米上的银纹与锅背的纹一模一样，出于安全没有吃下这粒米，而是放进布袋。半个月里他修行又停顿、精进缓慢，但打探到别人煮灵米不会出现银纹。趁黑三胖外出采购时，他去了杂役可以知晓修行常识的四海房，回房后取出灵米对比典籍中炼灵的图片，确认灵米上的银纹是炼灵纹。原文交代仙人修行有三炼，分别是炼药、炼器以及炼灵；炼灵是以特殊方法为物品强行注入天地之力的手段，遭天地所不允，存在一定几率，成功则威力大增，失败则物品成为废品，且可以叠加炼化，成功十次可让物品出现开天之变，越珍贵之物叠加炼灵后越恐怖，越到后面成功几率越小。典籍还说灵溪宗的护宗至宝是一件莫大机缘下炼灵了十次的天角剑。白小纯确定灵米出现炼灵纹的原因就是这口锅，决定这等隐秘万万不可让第二人知晓，等到深夜才来到锅旁，把被他操控的木剑按当日扔灵米的样子扔进了锅中。

**关键事件**：1.白小纯获奖励灵米，回房后灵气爆发昏睡 2.次日排出黑色杂质，被张大胖告知是体内杂质 3.龟形锅第一条纹路在生火后变亮 4.白小纯修行顺畅，三十息生出气感，六十息气脉成溪并完整游走一圈 5.白小纯修成紫气驭鼎功第一层即凝气第一层 6.白小纯操控木剑能直线漂浮 7.锅中灵米出现与锅背相同的银纹 8.白小纯在四海房查明炼灵，得知三炼与天角剑 9.深夜把木剑投入锅中试验

**逐章写法公式**：

- **情绪流向**：起：获奖励米，灵气爆发昏睡 → 承：排出杂质，修行突然顺畅并连破数关 → 转：灵米出现与锅背相同的银纹 → 合：查到炼灵，确认锅是秘密，深夜投剑试验
- **节奏配比**：慢铺垫 25% / 快冲突 5% / 爽点爆发 35% / 悬念留白 35%
- **本章结构公式**：灵米奖励与灵气爆发（状态变化） + 杂质排出后修行三级跳（行动） + 木剑漂浮练成隔空摄物（行动） + 银纹异常与查典籍揭炼灵（信息揭示） + 深夜投剑试验（悬念留白）
- **本章核心技巧**：把金手指的确认过程拆成身体变化、数字进度、典籍考据三段，让变强和秘密同时被读者掌握
- **卡点与伏笔**：结尾卡点：悬念类卡点，白小纯深夜把木剑扔进锅中，下章期待试验结果；埋设/回收伏笔：龟背几十条黯淡纹路与第一条亮纹 → 回收为炼灵锅的叠加机制；黑三胖外出采购 → 为白小纯能去四海房提供机会；灵溪宗护宗至宝天角剑 → 为后续以炼灵为核心的能力线定锚

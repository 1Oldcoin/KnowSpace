# 任务：重试与退避

## 最多几次

同一个任务最多重试 **3 次**，也就是总共最多执行 4 次（首次 + 3 次重试）。第 3 次重试仍失败，状态固定为 `Failed`，错误信息保留最后一次的原因。

## 退避曲线

从 **2 秒**起倍增，上限 **60 秒**：

```
2s → 4s → 8s → 16s → 32s → 60s(封顶)
```

每次还叠加 **±20%** 的随机抖动。抖动不是装饰：几十个任务同时失败时，没有抖动会让它们在同一毫秒一起重试，把刚恢复的服务再打一遍。

## 哪些错误不重试

- 参数校验失败（永远不可能成功）
- 文件不存在
- 权限不足
- 明确标记为不可重试的业务异常

重试这些东西只是把"立刻失败"变成"30 秒后失败"，用户等得更久、原因更模糊。

## 与回收的区别

重试是**任务自己失败**之后的再次尝试；回收是**执行者消失**之后的接手。两者计数分开：`attempt` 数重试，`recovery_count` 数回收。

所以一个任务可能 `attempt = 1` 但 `recovery_count = 2`——它被回收了两次，但一次都没真正报错。

## 手动重跑

任务中心可以对手动重跑失败任务：这会重置 `attempt` 与退避状态，等同一次"从头开始"。手动重跑不计入自动重试上限，但会留审计记录。
